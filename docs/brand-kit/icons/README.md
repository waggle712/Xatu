# Icons

24px grid, 1.75 stroke, round caps and joins, single ink via `currentColor`. These six are Xatu's own trust and buying icons; everything generic (home, search, heart, chat, profile) comes from Lucide at the same stroke so the set looks like one family.

- `verified.svg` — hive cell with a check. Verified maker. Colour `sage`.
- `protected-pay.svg` — shield with a rupee. Money held until delivery. Colour `sage`.
- `near-me.svg` — map pin. Near me / distance. Colour `ink-muted`.
- `pickup-slot.svg` — bag with a clock. Pick up from the maker at a time slot.
- `captured-in-app.svg` — camera. Photo or reel shot inside Xatu.
- `delivery-otp.svg` — keypad phone. The code the buyer shows at handover.
