# Logos

- `xatu-mark.svg` — the full-colour mark: a marigold hive cell with a plum flight path and the bee dot at its end. Use on `surface`, `surface-raised`, `surface-warm` and `plum`.
- `xatu-mark-mono.svg` — single ink, drawn with `currentColor`; set CSS `color` (`ink` on light grounds, `on-plum` on `plum`). Use for app icons on photos, stamps and one-colour print.
- `xatu-lockup.svg` — mark plus the lowercase wordmark set in Fraunces Bold. Outline the text before sending to print.

Clear space around the mark is one quarter of its width. Minimum size 20px on screen. Never recolour the hive cell, rotate the mark, or put it on a busy photo without a `surface-raised` chip behind it.
